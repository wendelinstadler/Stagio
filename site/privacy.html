Privacy Policy

Last updated: 29 October 2026

Stagio is a developer tool. It does not collect, transmit, sell or share any personal data, and it contains no analytics, tracking or advertising.

What is stored, and where

Projects, environments, pages, header presets, API requests, settings, recorded requests and collected page errors are stored only in your browser (chrome.storage) on your computer. You can export them yourself as a backup or team file.

Network requests

Stagio only sends requests to addresses you configure or explicitly trigger: opening your environments, server status checks, API requests you send, and files you import by link. No data is sent to the developer or any third party.

Page access

Stagio asks for access only to the addresses of your own projects, or to an address you choose (for example to record requests). On those pages it shows the environment marker, collects JavaScript errors and failed requests for the “Logs” tab, applies your header presets and records requests when you start a recording. None of this leaves your computer.

Optional helper

The Branch Manager uses a local helper program that you install yourself. It runs git/hg commands in folders you configure and only communicates with the extension on your computer.

Deleting data

Removing the extension deletes all stored data. The helper can be removed with npx stagio-helper --uninstall.

Datenschutzerklärung

Stand: 29. Oktober 2026

Stagio ist ein Werkzeug für Entwickler. Es sammelt, überträgt, verkauft oder teilt keine persönlichen Daten und enthält keine Analyse, kein Tracking und keine Werbung.

Was gespeichert wird und wo

Projekte, Umgebungen, Seiten, Header-Presets, API-Requests, Einstellungen, Aufnahmen und gesammelte Seitenfehler werden nur in deinem Browser (chrome.storage) auf deinem Computer gespeichert. Du kannst sie selbst als Backup oder Team-Datei exportieren.

Netzwerk-Anfragen

Stagio sendet Anfragen nur an Adressen, die du selbst einrichtest oder auslöst: deine Umgebungen öffnen, Server-Status prüfen, API-Requests, die du sendest, und Dateien, die du per Link importierst. Es werden keine Daten an den Entwickler oder Dritte gesendet.

Zugriff auf Seiten

Stagio fragt nur Zugriff auf die Adressen deiner eigenen Projekte an, oder auf eine Adresse, die du wählst (z. B. zum Aufnehmen von Requests). Dort zeigt es die Umgebungsmarkierung, sammelt JavaScript-Fehler und fehlgeschlagene Requests für den Tab „Logs“, setzt deine Header-Presets ein und nimmt Requests auf, wenn du eine Aufnahme startest. Nichts davon verlässt deinen Computer.

Optionales Hilfsprogramm

Der Branch Manager nutzt ein lokales Hilfsprogramm, das du selbst installierst. Es führt git/hg-Befehle in Ordnern aus, die du angibst, und spricht nur mit der Extension auf deinem Computer.

Daten löschen

Beim Entfernen der Extension werden alle gespeicherten Daten gelöscht. Das Hilfsprogramm entfernst du mit npx stagio-helper --uninstall.
