Set up the branch helper

Chrome extensions may not run programs on your computer. For the Branch Manager (git and Mercurial), Stagio uses a small local helper. Everything else works without it.

1. Install Node.js

You need Node.js 18 or newer. Check with node -v in a terminal.

2. Run one command

Open Stagio → Settings → Branch Manager and copy the command. It contains your extension ID:

npx stagio-helper <your-extension-id>

Works on macOS, Windows and Linux, for Chrome, Edge, Brave and Chromium. Run it on every computer you use.

3. Check the connection

Click Check connection in the settings. If it does not work, quit Chrome completely once and reopen it.

What the helper may do

Only inside folders that are git or hg repositories: status, list branches, recent commits, switch and create branches, pull, push, fetch, and read/write .stagio.json. No shell, validated branch names, never waits for a password.

Uninstall: npx stagio-helper --uninstall

Hilfsprogramm einrichten

Chrome-Extensions dürfen keine Programme auf deinem Computer starten. Für den Branch Manager (git und Mercurial) nutzt Stagio ein kleines lokales Hilfsprogramm. Alles andere funktioniert ohne.

1. Node.js installieren

Du brauchst Node.js 18 oder neuer. Prüfen mit node -v im Terminal.

2. Einen Befehl ausführen

Öffne Stagio → Einstellungen → Branch Manager und kopiere den Befehl. Er enthält deine Extension-ID:

npx stagio-helper <deine-extension-id>

Funktioniert auf macOS, Windows und Linux, für Chrome, Edge, Brave und Chromium. Auf jedem Computer einmal ausführen.

3. Verbindung prüfen

In den Einstellungen auf Verbindung prüfen klicken. Klappt es nicht, Chrome einmal ganz schliessen und neu öffnen.

Was das Hilfsprogramm darf

Nur in Ordnern, die git- oder hg-Repos sind: Status, Branches auflisten, letzte Commits, Branches wechseln und erstellen, Pull, Push, Fetch sowie .stagio.json lesen und schreiben. Ohne Shell, mit geprüften Branch-Namen, wartet nie auf ein Passwort.

Entfernen: npx stagio-helper --uninstall
