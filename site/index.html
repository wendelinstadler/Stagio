Switch between local, test and live.Zwischen Lokal, Test und Live wechseln.

A Chrome extension for web developers who work on the same site in several environments. Open the current page on another environment, send API requests, see what fails on the page and check your branches. Eine Chrome-Extension für Webentwickler, die an derselben Seite in mehreren Umgebungen arbeiten. Die aktuelle Seite in einer anderen Umgebung öffnen, API-Requests senden, Fehler der Seite sehen und Branches prüfen.

Free. No account. Data stays in your browser.Kostenlos. Kein Konto. Die Daten bleiben in deinem Browser.

FeaturesFunktionen

EnvironmentsUmgebungenOpen the same path on local, test or live. Every page gets a colored bar with the environment name, and actions on live need a second click.Denselben Pfad auf Lokal, Test oder Live öffnen. Jede Seite bekommt einen farbigen Balken mit dem Namen der Umgebung, Aktionen auf Live brauchen einen zweiten Klick.
Server statusServer-StatusA dot per environment shows whether it responds, with the response time.Ein Punkt pro Umgebung zeigt, ob sie antwortet, mit Antwortzeit.
Header presetsHeader-PresetsSend headers like X-Debug or an auth token with every request to an environment. Can be turned off per environment.Header wie X-Debug oder ein Token bei jedem Aufruf einer Umgebung mitschicken. Pro Umgebung abschaltbar.
API testerAPI-TesterRequests and responses in the style of Swagger UI. Imports OpenAPI, cURL, Postman and HAR. One request can be sent to two environments to compare the responses field by field.Requests und Antworten im Stil von Swagger UI. Importiert OpenAPI, cURL, Postman und HAR. Ein Request lässt sich an zwei Umgebungen senden, um die Antworten Feld für Feld zu vergleichen.
LogsLogsJavaScript errors, console.error and failed requests of your pages. The count is shown on the toolbar icon.JavaScript-Fehler, console.error und fehlgeschlagene Requests deiner Seiten. Die Anzahl steht auf dem Icon.

API testerAPI-Tester

If your backend serves an OpenAPI document (for example /v3/api-docs with springdoc), Stagio finds it and creates all requests. Variables like {{token}} are set per environment, so the same request works everywhere. Liefert dein Backend ein OpenAPI-Dokument (zum Beispiel /v3/api-docs mit springdoc), findet Stagio es und legt alle Requests an. Variablen wie {{token}} werden pro Umgebung gesetzt, derselbe Request funktioniert also überall.

BranchesBranches

Shows the current branch of each repository with changed files and unpushed commits. New branches can be named from a ticket number, for example feature/ABC-123-fix-login. Zeigt den aktuellen Branch jedes Repos mit geänderten Dateien und ungepushten Commits. Neue Branches lassen sich aus einer Ticket-Nummer benennen, zum Beispiel feature/ABC-123-login-reparieren.
